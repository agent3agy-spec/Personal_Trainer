# _out_of_scope · programs kept, never served

_This folder holds programs the trainer no longer offers. Nothing here can be matched, chosen or built: `engine/core.py` reads only the files directly in `doctrine/programs/`, and the web bundle skips this folder._

## Why

On 13 nov 2026 the trainer's scope was set (`../../00_MISSION.md`): adults 18 to 40 who train in a gym, a home gym with real kit, or outdoors for running and other cardio. These five programs serve people outside that scope:

| program | why it is out |
|:-|:-|
| `calisthenics-rr-3` | bodyweight-only skill training |
| `home-fullbody-2to4` | a home plan that runs on bodyweight alone |
| `kettlebell-rop-3` | a kettlebell-only plan |
| `kettlebell-ss-5` | a kettlebell-only plan |
| `older-strong-3` | built for people over 60 |

## When they come back

Only with a scope change written in `00_MISSION.md` first, then the interview, the matrix and the web page updated to offer them, and the tests that covered them restored. Move a file back up one folder to make it runnable again; nothing else in it needs to change. Until then, do not edit these files and do not reference them from the doctrine, the modules, the skill or the site.
