## The marks

- **[checked]** confirmed this session in an abstract, a PubMed record, an official support page or an official docs page. Never a full paper.
- **[snippet]** (file 02) and **[seen]** (file 03) mean the same thing: confirmed in a search engine's extract quoting the named source.
- **[believe]** from memory or a secondary site. A lead, never a hard rule until it is checked. Every [believe] number a program or the engine relies on is listed under "To verify" in `doctrine/schools/INDEX.md`.
- **[inferred]** reasoned from checked parts.

Evidence levels (A, B, C, G) are defined in `doctrine/schools/INDEX.md`. Files 02 and 04 also use their own labels (META, RCT, OBS, COACH, MKT; guideline, SR/MA, RCT, expert), explained at the top of each.

## The network limit

Page fetches were blocked for every host tried in the research session (pubmed, pmc, nhs.uk, hyrox.com, rpstrength.com, strongfirst.com, reddit, docs.github.com and others). Only web search worked. So no paper or official page was read in full: **[checked] means checked in an abstract or an official excerpt**, and file 05's GitHub items are [believe] until milestone 1. Each file ends with its own list of what could not be verified.

These notes are kept as found: they are not edited to match later doctrine.
