# me · your memory

Everything the trainer knows about you lives here, and only here, in your own private copy. The trainer writes these files for you; you can read them on GitHub any time.

| file | what it is |
|:-|:-|
| `PROFILE.md` | your goal, your week, your place and kit, your limits. Edit it by hand or say `/train goals` |
| `PLAN.md` | the program you picked, your add-ons, when it is reviewed |
| `LOG.md` | every session you did, as a table |
| `log.jsonl` | the same log, for the engine (the truth) |
| `state.json` | where you are: block, week, your weights. Rebuilt from the log if it ever breaks |

To erase it all: say `/train forget`.
